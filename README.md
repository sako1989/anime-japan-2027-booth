# Anime Japan 2027 — Booth presentation

[Open the live presentation](https://sako1989.github.io/anime-japan-2027-booth/)

Interactive booth walkthrough with visitor-flow simulation, four facade options,
section details and saved Blender renders. Use Next / Back to present or select a chapter.

Design studies and simulated visitor behavior are illustrative, not fabrication
drawings or a calibrated crowd-capacity model. Generated artwork studies are not
original production storyboards.

Static HTML, JavaScript, CSS and bundled assets; no build or server required on
GitHub Pages. Publish from the root of the main branch. For local preview, run
`python3 -m http.server 8000` and open http://localhost:8000/.
